# Portfolio

This is my personal portfolio website built to showcase my skills, projects, and learning journey as a developer. The site highlights my technical abilities, certifications, and hands-on work in areas like web development, programming, and electronics. It also includes a contact section so that recruiters or collaborators can easily reach me.

I designed this portfolio using modern frontend technologies with a focus on responsive design, clean UI, and smooth user experience across devices. The project reflects both my technical knowledge and my passion for continuously learning and improving as a software developer.
